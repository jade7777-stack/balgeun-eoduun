# 밝은 쪽, 어두운 쪽

초등 5학년 미술 1학기 4단원 「실감 나는 사물과 풍경」 — 주변 사물을 실감 나게 그리기(2차시) 학생용 수업 웹앱.

**배포 주소: https://balgeun-eoduun.vercel.app**

- 빛의 방향과 거리를 움직여 보며 밝은 부분·어두운 부분·그림자·반사광 관찰하기
- 화면에서 연필로 밑그림을 그리고 명암 넣기 (겹칠수록 진해지는 흑연 질감)
- 샘보드에 올릴 카드 만들기, 활동지 인쇄

`index.html` 한 파일로 동작합니다. 별도 빌드가 필요 없습니다.
